# SM Tailscale Proxy

Home Assistant add-on: Tailscale exit node + SOCKS5 proxy for SM proxy network.

## Installation

### Option 1: Local add-on
1. Copy this folder to `/addons/sm-tailscale-proxy/` on your HA instance
2. Go to Settings > Add-ons > Add-on Store
3. Click the refresh button (top right)
4. Find "SM Tailscale Proxy" under Local add-ons
5. Install and configure

### Option 2: GitHub repository
1. Go to Settings > Add-ons > Add-on Store
2. Click three dots (top right) > Repositories
3. Add your GitHub repo URL
4. Install from the store
